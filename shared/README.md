# Shared

Общие типы, интерфейсы и утилиты, используемые во всех слоях.

## Планируемые файлы
```
shared/
├── types/
│   ├── graph.ts        ← ServiceNode, Edge, GraphModel
│   ├── schema.ts       ← Schema, SchemaField, SchemaRef
│   └── events.ts       ← WsEvent, FileChangeEvent
└── utils/
    ├── logger.ts
    └── path-utils.ts
```
